# 📝 Liste de Tâches – Application Web

## 🚀 Description

Cette application web est une **simple To-Do List** développée avec **HTML, CSS et JavaScript pur (sans framework)**. Elle permet :

- ✅ D'ajouter des tâches
- ✅ De marquer des tâches comme terminées
- ✅ De supprimer des tâches
- ✅ De conserver les tâches entre les sessions grâce au **localStorage**

---

## 📁 Fichiers

- **index.html** : structure HTML de l'application
- **style.css** : styles pour un design propre et responsive
- **app.js** : logique JavaScript pour gérer l'ajout, la suppression, la complétion et le stockage local

---

## 💻 Installation & Lancement

### 1. Sur Replit

1. Accédez à [Replit](https://replit.com)
2. Créez un nouveau **Repl** → choisissez **« HTML, CSS, JS »**
3. Collez le contenu des fichiers fournis dans leurs emplacements respectifs :
   - `index.html`
   - `style.css`
   - `app.js` (ou `script.js` selon votre fichier)
4. Cliquez sur **« Run »** pour lancer l’application.

### 2. Localement

1. Téléchargez les trois fichiers dans un même dossier.
2. Ouvrez `index.html` avec votre navigateur.

---

## 🛠️ Fonctionnalités

- **Ajouter une tâche** via le champ de texte et le bouton « Ajouter » ou la touche **Entrée**
- **Marquer comme terminée** : cliquez sur le bouton ✔️
- **Supprimer une tâche** : cliquez sur le bouton 🗑️
- **Persistant** : vos tâches sont sauvegardées dans le **localStorage** de votre navigateur
